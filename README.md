# AI 어린이 뉴스 연구소

초등학생(1~6학년)을 위한 AI 기반 어린이 뉴스 문해력 학습 웹앱입니다.

- 사이트: https://student-ai-news.vercel.app
- `main` 브랜치에 push하면 Vercel이 자동으로 다시 배포합니다.

## 주요 기능
**뉴스 읽기**
- 12개 분야(과학·우주, IT·AI, 환경·날씨, 동물·자연, 사회, 교육, 경제, 세계, 어린이, 역사, 문화·예술, 스포츠) 뉴스 목록·검색·더 보기, 추천 학년 표시
- 학년별 보기(모든 학년 / 1~2 / 3~4 / 5~6학년), 안 읽은 뉴스만 보기, 분야 둘러보기
- 언론사·보도 날짜·원문 링크, '원문과 비교해 보세요' 상자, 어린이 기사 검토 기록
- 읽어 주기(TTS), 글자 크기, 어두운 화면(기본)·밝은 화면, 스크랩, 읽은 기사 표시, 다음에 읽을 기사
- 화면마다 주소가 있어요: `#/`(처음), `#/cat/science`(분야), `#/news/기사id`(기사), `#/study`(공부방), `#/me`(수첩).
  뒤로 가기·새로고침이 되고, 기사마다 '링크 복사'로 주소를 보낼 수 있어요. 맨 위 제목을 누르면 언제나 처음 화면으로 가요.

**오늘의 공부 (처음 화면)**
- 오늘의 미션 4가지(기사 읽기, 낱말 3개, 퀴즈·연습, 생각 쓰기) — 모두 마치면 +10P
- 오늘의 낱말, 오늘의 문장(사실일까 의견일까) — 날마다 바뀌어요

**선생님용 학습지 인쇄**
- 기사 화면의 '학습지 인쇄' → 본문, 핵심 낱말, 사실·의견 표, 내용 퀴즈, 생각 쓰기 칸, 정답(다음 쪽)이 담긴 A4 학습지

**기사마다 학습 활동 (AI 키 없이도 바로 쓸 수 있어요)**
- 낱말 익히기 — 본문 밑줄 낱말을 누르면 뜻이 나오고, '알아요 / 다시 볼래요'로 표시
- 사실·의견 가려내기 — 문장마다 사실인지 의견인지 고르고 까닭과 함께 채점
- 내용 퀴즈 — 검토한 4지선다 3문제, 틀린 문제는 오답 노트로
- 생각 쓰기 — '나는 ~라고 생각해요. 왜냐하면 ~' 틀로 내 생각과 까닭 쓰기

**공부방**
- 낱말 카드(모든 낱말 / 못 외운 낱말 / 다시 볼 낱말), 낱말 퀴즈 10문제, 사실·의견 연습 10문제, 제목 맞히기 10문제(중심 내용 찾기), 최고 기록

**AI 읽기 도우미 (ANTHROPIC_API_KEY 필요)**
- AI 쉽게 읽기(1~2 / 3~4 / 5~6학년 눈높이), AI 문장 분석(기사 전체를 사실·의견으로)

**내 탐정 수첩**
- 포인트·10단계 등급, 배지 12개, 분야별 읽기, 읽기 달력, 낱말 수첩, 생각 노트, 오답 노트, 스크랩

## 기사 업데이트와 검토
- 기사는 `data/articles.js`에 있어요. 모두 실제 보도된 기사를 어린이가 읽기 쉽게 다시 정리한 글이에요.
- 매일 아침 예약 작업이 [CURATION.md](CURATION.md) 기준으로 기사를 고르고 검토해 3~5개를 더해요. 기사는 분야마다 12개, 모두 150개까지 두고, 넘치면 그 분야에서 가장 오래된 기사부터 지워요.
- '분야 둘러보기'용으로 모은 지난 기사(`"archive": true`)도 보도된 지 60일 안의 실제 기사이고, 매일 기사와 같은 기준으로 검토했어요.
- 올리기 전에 `node scripts/check-articles.mjs`로 형식, 금지 낱말, 중복, 날짜, 학습 자료를 검사해요. '검사 통과'가 나와야만 올려요.
- 직접 기사를 고칠 때도 같은 검사를 돌려 주세요.

## AI 기능 켜기 (선생님이 한 번만)
AI 기능은 서버 함수 `api/ai.js`가 Anthropic API를 대신 불러 줍니다.
학생은 키를 입력할 필요가 없고, 키는 브라우저에 절대 전달되지 않습니다.

1. Vercel 대시보드 → `student-ai-news` 프로젝트 → **Settings → Environment Variables**
2. `ANTHROPIC_API_KEY` = 본인의 Anthropic API 키 (`platform.claude.com`에서 발급) 추가
3. **Deployments**에서 최신 배포를 **Redeploy**

확인: `https://student-ai-news.vercel.app/api/ai` 에서 `"ready":true`가 보이면 준비 완료입니다.

### 선택 설정
| 변수 | 설명 |
| --- | --- |
| `AI_MODEL` | 사용할 모델 (기본값 `claude-haiku-5-5`) |
| `KV_REST_API_URL` / `KV_REST_API_TOKEN` (또는 `UPSTASH_REDIS_REST_URL` / `UPSTASH_REDIS_REST_TOKEN`) | Upstash Redis를 연결하면 같은 기사·학년의 AI 결과를 반 전체가 함께 써서 비용과 대기 시간이 줄어듭니다. |

### 서버 함수의 보호 장치
- 같은 사이트에서 온 요청만 받습니다.
- IP당 10분에 120회까지 (한 교실이 같은 IP를 써도 넉넉하게).
- 기사 길이 제한, AI 결과 형식 검사(실패 시 한 번 재시도), 결과 캐시.

## 파일 구성
- `index.html` — 화면 전체 (HTML/CSS/JS, 빌드 과정 없음)
- `data/articles.js` — 기사와 학습 자료
- `CURATION.md` — 어린이 기사 고르기·쓰기 기준
- `scripts/check-articles.mjs` — 기사 데이터 검사기
- `api/ai.js` — AI 요청을 처리하는 Vercel 서버 함수
